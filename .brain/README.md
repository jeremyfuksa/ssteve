## Usage

The brain system automatically activates based on:

1. **File types**: `.rs`, `.js`, `.py` files trigger relevant contexts
2. **Keywords**: "debug", "feature", "audio", "decode" trigger specific templates
3. **Task complexity**: Simple tasks use L1+L2, complex debugging uses L1+L2+L4

## Context Layers

- **L1 (Core)**: Always active - project overview, architecture, status
- **L2 (Development)**: File operations, build processes, directory structure  
- **L3 (Feature)**: Current features, Phase 5 planning, UI components
- **L4 (Deep)**: Performance details, audio pipeline, complex debugging

## Key Principles

- **colaclanth/sstv library**: NEVER REPLACE - produces reference-quality results
- **"Good Enough" approach**: Simple solutions first, optimize only if needed
- **Real-time audio**: File-based approach maintains timing precision
- **Phase-based development**: Each major feature gets its own branch
- **Cultural Bridge Mission**: Technology that heals amateur radio community divisions
- **Honda/Acura Strategy**: Premium refinement of proven amateur radio functionality
- **Multi-Agent Architecture**: Parallel development with universal Python core
